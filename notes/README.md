# 内部历史归档

archive保存旧规划、来源快照、模型联调和价值评审。它们解释项目如何演变，不是当前产品文档，也不能覆盖AGENTS.md、代码、测试或最新用户要求。包含旧版本功能、状态和未采纳建议的描述应按记录日期理解。
